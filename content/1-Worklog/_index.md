During the 8-week internship program with the First Cloud AI Journey (FCAJ), I systematically learned, practiced, and deployed cloud architecture solutions on Amazon Web Services (AWS). The program covered fundamental to advanced AWS services, including IAM, VPC, EC2, RDS, Auto Scaling, Load Balancing, CloudWatch, IAM Identity Center, and AWS CLI. Additionally, I developed a full-stack application with modern frontend technologies (React/Node.js) integrated with AWS cloud infrastructure.

This worklog documents the entire technical journey, detailed weekly tasks, key learning achievements, and hands-on deployment experiences.

Below is the weekly summary of tasks completed during the internship:

**Week 1:** [Onboarding, AWS Free Tier 2025, IAM & VPC Fundamentals](1.1-week1/)

**Week 2:** [Advanced VPC, EC2 Fundamentals & Multi-OS Application Deployment](1.2-week2/)

**Week 3:** [Amazon RDS, High Availability, Backup & Application Integration](1.3-week3/)

**Week 4:** [Auto Scaling, Load Balancing, Frontend Design & AWS Budgets](1.4-week4/)

**Week 5:** [Frontend Development with Node.js, CloudWatch Monitoring & AWS Support](1.5-week5/)

**Week 6:** [Frontend Completion, AWS CLI & Hybrid DNS with Route 53 Resolver](1.6-week6/)

**Week 7:** [Advanced AWS CLI Operations & IAM Identity Center Setup](1.7-week7/)

**Week 8:** [Final Code Implementation, Deployment, Report Writing & Project Submission](1.8-week8/)
